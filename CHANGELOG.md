# Changelog

## Current production line

SmartProBono is publicly available on the Apple App Store.

The mobile configuration is currently version **1.0.0**. The shipped product centers on trusted contacts, Safety Mode, location capture/sharing, optional recording, calm guidance, and local session history.

Repository work may include features ahead of the currently published build; production release notes should only claim functionality that has passed device QA and App Store release.

## Policy

Add a dated entry whenever the App Store marketing version changes. Keep App Store changes separate from unreleased repository work.
